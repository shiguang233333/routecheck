结果怎么读

出口指纹来自 8 个独立的 IP 查询服务，其中 myip.ipip.net 与 whois.pconline.com.cn 位于国内，用来对照国内直连与国外代理的出口；pconline 通过 JSONP 读取。它们如果给出不同 IP，通常意味着域名级分流正在工作；如果相同，可能全局走同一节点，也可能只是全部直连。判定会按 IPv4 / IPv6 分组，避免双栈地址被误认为分流。

测不到什么

浏览器不能发 ICMP，这里的延迟是一次 HTTP 请求的往返时间；首次请求还包含 DNS、连接与 TLS。它适合比较线路快慢，不等于 ping 命令的 RTT。被拦截或超时的探测会在控制台留下网络错误，那是探测结果本身。
